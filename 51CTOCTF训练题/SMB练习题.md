# SMB信息泄露练习题

## SMB简介

一种网络文件共享协议，主要用于共享资源

通常使用以下端口进行通信

> TCP端口445和139端口

Samba 是一个开源软件，它实现了 SMB 协议，使 Linux 和 UNIX 系统能够与 Windows 系统共享文件和打印机。

> FTP协议是文件传输协议，而SMB协议是文件共享协议
